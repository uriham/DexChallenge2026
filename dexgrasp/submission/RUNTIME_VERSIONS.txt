--- Notes ---
- IsaacGym requires `import` order: isaacgym-touching modules (utils.config,
  utils.parse_task, etc.) must be imported before `import torch`, otherwise
  raises "PyTorch was imported before isaacgym modules".
- If `ImportError: libpython3.8.so.1.0: cannot open shared object file` occurs,
  run: sudo apt install libpython3.8-dev (per README) and/or ensure
  LD_LIBRARY_PATH includes the conda env's lib directory.
- Reproduce this file with:
    conda list -n DexGraspMotionChallenge2026 > RUNTIME_VERSIONS_full.txt
  (full dump; this file lists only the packages relevant to running inference)
